# Kanazawa

金沢検定の問題を学習・管理するiPhone / iPad向けSwiftUIアプリです。問題と選択肢、答え・解説を表示し、実施回・級・分類・キーワードで絞り込めます。アプリアイコンは、濃い背景に金色の加賀梅鉢を配置しています。

## 主な機能

- メイン画面最上部のタイトルは「金澤検定」です。

- 初回起動時にSQLiteのDB・テーブルを作成し、同梱の54問を登録。既存DBの問題は保持します。
- 実施回に応じた級、実施回・級に応じた分類の候補を表示。選択変更で自動検索します。
- キーワード欄と検索ボタンを1行に配置し、検索結果の件数をfootnoteサイズで表示します。 キーワード欄の×を押すと、実施回・級・分類の選択を保持してキーワードの絞り込みを解除し、該当結果の先頭を表示します。
- 下部ナビゲーションと問題文・選択肢の枠上の左右スワイプで問題を移動。スワイプ時は方向に合わせた切替アニメーションを表示します。ナビゲーション中央の現在位置／検索件数は通常の文字色・footnoteサイズで表示します。
- 選択肢の文字色はライト・ダークモードに対応します。青色の指定は丸印・チェック印だけに適用し、文字は通常の文字色で表示します。
- 最後に参照した問題と実施回・級・分類・適用済みキーワードを保存し、次回起動時に復元します。
- 選択肢を選ぶと答え・解説を表示。専用ボタンで表示・非表示を切り替えられます。自動の正誤判定は行いません。
- 編集画面の左スワイプで次、右スワイプで前の問題へ移動。変更は移動前に自動保存し、検索結果の最後から次へ進むと新規入力画面を表示します。
- 専用画面で問題を新規登録・編集・削除。必須項目・整数の検証、保存失敗時の入力保持、未保存変更の破棄確認に対応します。削除は編集画面の赤文字のボタンから確認後に実行します。
- 全問題をJSONまたはCSVでエクスポート。インポートは内容から形式を判別し、実施回を複数選択して追加・置換できます。
- About画面にアイコン、Version、Revisionを表示します。

集合メニューの構成：

```text
新規
編集
────
インポート
エクスポート
────
About
```

## 開発・起動

1. このリポジトリを取得します。
2. `kanazawa01.xcodeproj`をXcodeで開きます。
3. Signing & Capabilitiesで使用する開発チームと署名設定を確認します。
4. iOS 18.4以降の実機またはSimulatorを選び、ビルド・実行します。

現在のプロジェクトの最低対応OSはiOS 18.4です。ビルド・動作確認は利用者が実施する運用です。今回のソース修正ではビルド・アプリ実行を行っておらず、確認済みの安定動作を保証するものではありません。確認項目は[確認手順.md](確認手順.md)に記載しています。

## 参照位置の保存

問題の表示ごとにUserDefaultsへ問題IDと検索条件を保存します。検索結果が0件の場合は最後に参照した問題の記録を維持します。次回起動時はDB読込後に検索条件と問題を復元します。問題IDに加えて実施回・級・問題番号・問題文も照合し、別の問題への誤復元を防ぎます。復元できない場合は、有効な検索条件の先頭または0件表示になります。答えの表示・選択状態は復元しません。アプリ削除時には参照位置の記録も失われます。

## 編集・削除

編集画面のタイトルは「編集」です。上部左側に「キャンセル」、その右に赤文字の「削除」を表示します。iOS 26以降ではツールバーの固定スペーサーでボタンの共有枠を分け、文字を省略しない指定をしています。タイトルの位置は変更していません。このAPIを含むソースのビルドにはiOS 26 SDKを含むXcodeが必要です。最低対応OSはiOS 18.4を維持しています。

削除時は、編集開始時の実施回・級・問題番号を示して確認します。確認すると元の問題IDを削除し、未保存の変更も破棄します。成功後は画面を閉じ、一覧・件数・検索候補を更新して隣接する問題を表示します。残り0件の場合は空状態になります。失敗時は入力を保持し、理由を表示します。

新規登録画面には削除ボタンを表示しません。保存・削除中は入力と閉じる操作を無効にします。ボタンの実機表示を含め、今回の変更後のビルド・動作確認は未実施です。

### 編集画面のスワイプ移動

編集を開いた時点の検索結果の順序を保持し、左スワイプで次、右スワイプで前の問題の編集へ移動します。保存によって問題番号や検索条件に一致する内容が変わっても、この編集画面を閉じるまでは同じ順序で編集できます。移動先ではフォームを先頭から表示します。

変更がある場合は移動前に自動保存します。必須項目の不足・整数の不正・DB保存失敗では移動せず、入力を保持して理由を表示します。変更がない場合は保存せずに移動できます。保存・削除中および確認アラート表示中はスワイプ移動を抑止します。

先頭から前には移動しません。最後から次へ進むと空の新規入力画面になります。そこから右スワイプすると最後の問題へ戻ります。新規入力に変更があれば保存成功後に戻り、未入力なら保存せずに戻ります。集合メニューの「新規」から直接開いた画面はスワイプ移動の対象外です。「保存」ボタンは従来どおり保存して画面を閉じます。

DB保存後に一覧再読込が失敗した場合は、保存済みのIDを保持して移動を止めます。編集画面を閉じ、閲覧画面で再読込してください。今回の変更後のビルド・動作確認は未実施です。

## データとインポート

DBはアプリのDocuments内の`kanazawa_sqlite3`に保存します。初期登録済み情報は`app_metadata`に保存し、再起動時の重複登録を防ぎます。既存DBは自動削除しません。アプリをアンインストールするとDBも削除されるため、必要なデータは先にエクスポートしてください。

- **追加**：選択した実施回の問題を追加します。同一問題の重複排除は行いません。
- **置換**：DB全体を、選択した実施回の問題で入れ替えます。未選択の回の既存問題も削除されます。実行前に件数と置換範囲を確認します。
- インポートはUTF-8、20MB以下、問題1件以上が対象です。全件検証後にトランザクションで保存し、保存失敗時はロールバックします。
- エクスポートは検索結果だけでなく全問題を対象とし、20MB以下に制限します。インポート時のIDは新しく採番します。
- 元データ100件のうち46件は問題文などが未入力のため、初期登録は内容のある54問です。元データは変更せず保存しています。
- 既存DBの未入力レコードもエクスポートに含まれますが、再インポートには必須項目の補完が必要です。

### CSV

次の15列を見出し付きで使用します。引用符、カンマ、セル内改行、CRLF、UTF-8 BOMに対応します。

```text
ID,通番,実施回,レベル,分類,問題番号,問,選択肢1,選択肢2,選択肢3,選択肢4,答え,解説,実施日,備考
```

### JSON

Kanazawa形式のオブジェクトとして書き出します。`format`は`Kanazawa`、`version`は`1`、`questions`は問題の配列です。各問題はCSVと同じ全項目を保持します。

問題のキー：`id`, `seq`, `kai`, `level`, `category`, `number`, `question`, `sel1`, `sel2`, `sel3`, `sel4`, `answer`, `description`, `hiduke`, `bikou`。数値は`id`, `seq`, `number`、それ以外は文字列です。
